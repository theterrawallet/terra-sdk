# Terra Wallet SDK

Official SDKs and widgets to connect Terra Wallet and accept payments with Terra Pay.

**Status: in development.** Nothing is released yet. The npm names under `@terrawallet/` are reserved by Terra Wallet and contain no working code until the first release is announced at https://developers.terrawallet.us.

Only install Terra packages linked from https://developers.terrawallet.us. Every official release is published from this repository by GitHub Actions through npm trusted publishing, never from a personal machine.
